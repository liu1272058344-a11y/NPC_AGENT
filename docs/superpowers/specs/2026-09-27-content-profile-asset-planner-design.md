# AI Game Content Pipeline Agent：游戏内容档案与独立美术资源规划

## 目标

将世界观、角色和美术资源规划连接成可复用的内容生产闭环，同时允许美术资源规划接收外部手动素材。

## 核心模型

资源生成上下文统一为 `contentProfile`：

- `name`：用户可识别的档案名称
- `source`：`agent` 或 `manual`
- `world`：可选的结构化世界观
- `npc`：可选的结构化角色
- `notes`：可选的手动补充素材

Agent 生成世界观和角色后，前端将二者组合为一份完整内容档案，而不是让用户分别选择两个来源。

## 资源规划流程

美术资源规划作为独立入口存在。用户可以选择完整内容档案、仅使用档案中的世界观、仅使用角色，或粘贴外部素材。前端展示当前生成依据预览；后端只把用户实际选择的上下文传给模型。

## 提示词规则

- 世界观字段约束场景、时代、氛围、核心规则和冲突。
- 角色字段约束姓名、身份、功能、性格、背景和说话风格。
- 世界观与角色同时存在时，提示词必须保持二者一致。
- 手动素材作为事实来源，不得被模型替换成无关设定。

## 兼容性

保留现有 `world` 字段作为后端兼容输入；新增 `contentProfile` 后逐步迁移。导出结构使用稳定的 `world`、`npc`、`notes` 字段，方便未来接入 Godot。

## 验收标准

1. 完成 NPC 创建后可看到一份完整内容档案。
2. 美术资源规划无需先进入 NPC Creation 页面。
3. 用户可以选择完整档案、部分档案或手动输入素材。
4. 生成请求包含实际选中的上下文，后端拒绝完全没有上下文的请求。
5. 测试和生产构建通过。
