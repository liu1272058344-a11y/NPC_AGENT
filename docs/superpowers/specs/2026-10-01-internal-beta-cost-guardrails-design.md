# 内测访问与非 API 成本防护设计

## 目标

项目在 Vercel Hobby 与现有 Neon、Vercel Blob 免费额度内面向受控内测，不购买额外服务。所有业务功能只允许持有共用内测口令的测试者使用，并在应用层对可能消耗函数、数据库、存储或流量额度的操作设置硬上限。

## 访问模型

- 新增普通内测口令 `INTERNAL_BETA_PASSWORD` 与管理员口令 `INTERNAL_BETA_ADMIN_PASSWORD`，两者仅存在于服务端环境变量。
- 新增会话签名密钥 `INTERNAL_BETA_SESSION_SECRET`。登录成功后签发短期、签名、`HttpOnly`、`Secure`、`SameSite=Strict` Cookie；Cookie 不包含口令。
- 登录接口是唯一面向普通访客开放的业务接口。Cron 继续只接受 `CRON_SECRET`，不依赖浏览器会话。
- 所有其余 `/api` 路由先验证内测会话；普通测试者可使用产品，管理员额外可读取项目总用量。
- 前端未登录时只渲染登录页；收到 401 时清理本地登录状态并返回登录页。静态 HTML、CSS、JS 可公开下载，但不含密钥和用户数据。
- 本地开发在未配置 `INTERNAL_BETA_PASSWORD` 时允许显式开发旁路；Vercel 环境缺少相关变量时业务 API 必须失败关闭。

## 成本硬上限

- 单工作区现有限额保持为 20 张、100 MB、保留 30 天。
- 全项目默认上限为 200 张、1 GiB，分别由 `INTERNAL_BETA_MAX_IMAGES` 与 `INTERNAL_BETA_MAX_BYTES` 覆盖。
- 全项目每日最多执行 30 次成本操作，由 `INTERNAL_BETA_DAILY_ACTIONS` 覆盖。成本操作包括图片生成、外部图片导入保存和 NPC/内容生成请求。
- 每次成本操作必须在调用上游模型或下载外部图片之前，以数据库原子操作预留额度。失败的上游请求不返还当日次数，以避免重试风暴绕过限制。
- 资产写入必须在同一数据库事务中检查工作区限额和项目总图片/字节限额，避免并发超卖。达到上限返回 429 与稳定错误码，不影响读取、下载和删除。
- 删除和过期清理会降低当前图片数与字节数，但不返还当日操作次数。

## 输入防护

- 内测阶段不设置登录频率、每分钟请求数或并发请求频率限制；共享口令必须使用高熵随机值并支持随时轮换。
- 外部图片只允许 `https:`，限制重定向次数、下载超时和最大响应体；超过项目剩余空间或单文件上限时中止。
- 客户端提供的工作区 ID 仍用于数据分组，但不能作为身份或绕过项目总额度的依据。

## 生成质量不变

- 成本防护不得缩短、摘要、重写或降低 Prompt 的细节量，也不得改变现有模型选择、审查轮次或生成参数。
- 图片不得为了节省平台额度而降采样、压缩、降低分辨率或切换到低质量模型；单次生成质量保持现状。
- 每日总成本上限只在累计达到阈值后拒绝新的成本操作，不改变阈值以内任何请求的内容或质量。

## 用量监管

- 管理员会话可访问 `/api/internal-beta/usage`，返回项目图片数、字节数、当日成本操作数、各项上限及使用比例，不返回密钥或 tester 内容。
- 设置页仅在管理员会话下显示“内测用量”卡片；达到 70% 显示提醒，达到 90% 显示高风险提示，达到 100% 显示已暂停新增操作。
- 不接入短信、邮件或第三方付费监控。项目所有者继续在 Vercel Usage 与 Neon 控制台查看平台级额度；应用内硬上限用于提前阻断。

## 数据与迁移

- 新增每日成本计数表，不记录登录来源或 IP。
- 迁移应可重复执行，并为过期的每日计数清理建立索引。
- 管理员用量查询基于数据库真实资产记录和当日计数，不依赖浏览器缓存。

## 错误与失效策略

- 未登录返回 `401 INTERNAL_BETA_AUTH_REQUIRED`；权限不足返回 `403 INTERNAL_BETA_ADMIN_REQUIRED`。
- 每日上限返回 `429 DAILY_COST_LIMIT_REACHED`；全项目资产上限返回 `429 PROJECT_ASSET_LIMIT_REACHED`。
- Vercel 生产环境缺少必需的内测配置时返回 `503 INTERNAL_BETA_NOT_CONFIGURED`，不得降级为公开访问。
- 数据库不可用时成本操作失败关闭；只读页面可显示服务暂不可用，但不能跳过额度检查执行生成或保存。

## 验收标准

- 未登录用户无法调用任一业务 API，无法从前端看到业务工作区。
- 普通口令可使用产品但无法读取项目总用量；管理员口令可读取用量。
- 并发请求不能突破每日 30 次、项目 200 张或 1 GiB 默认上限。
- 达到任一硬上限后不再调用外部模型、不再下载来源图片、不再写入 Blob。
- 阈值以内的 Prompt、模型、审查轮次、图片参数和图片质量与改动前完全一致。
- 现有测试保持通过，新增认证、配额、迁移、质量透传和前端状态测试通过，构建成功。
