# 游戏内容工作室与文生图工作台简化规格

日期：2026-10-03。基线：本地 master 5cd4c7a。用户已确认下述职责结构；本文待用户审阅后进入实施计划。

## 目标

用户完成游戏内容设计后，点击“一键用于文生图”，立即看到已填入提示词的图片工作台，可以删改并生成图片。图片工作台不再要求分类、选择草稿或新建条目。参照用户提供的即梦截图的输入与结果布局，使用本产品的模型能力和视觉样式，不添加尚不支持的画布、参考图、批量生成或商业功能。

## 导航与职责

保留项目总览、游戏设定、世界构建、资产库、导出中心和设置。“角色工作室”改为“游戏内容工作室”；移除“美术生产”独立导航，将图片生成集中到唯一“文生图工作台”。旧内部入口映射到新职责，已有档案、历史和本地草稿不删除。

世界构建负责生成和编辑世界规则、氛围及视觉方向。游戏内容工作室负责世界观档案入口，以及角色、地图、场景、道具、服饰的设计和 Prompt 生成。世界观编辑复用世界构建；其余类别使用对应设计字段，角色不默认限定为人类。服饰作为内容类别支持设计、保存、筛选与图片来源关联，提供用途、适用对象、结构、材质、色彩及展示要求，不能强制人类模特。

游戏设定仍负责游戏目标和玩法需求；有可用于生图的视觉 Prompt 才提供交接，不将一般玩法说明冒充已经完成的视觉 Prompt。该页已有 Prompt 的交接与其他来源采用同一接口。

## 文生图工作台

页面以大提示词输入框为中心，下方是当前模型、尺寸和生成按钮，上方或下方展示图片结果。反向提示词和保存归属属于可展开的次要操作。页面不出现内容类别标签、条目设计字段、草稿选择器、设计 Prompt 生成按钮或新建条目要求。模型只展示和允许选择已支持的选项，凭据继续由设置管理。

直接打开工作台可纯手写生成。输入和来源状态在工作台会话中保留，切回页面不能重复带入旧交接覆盖用户修改。新的明确交接只消费一次；如果当前有未提交文本或未保存图片，需要可保留或取消的确认，不静默丢失结果。生成失败保留输入，保存失败保留图片以便重试；生成与保存互斥。

## 一键交接

统一交接数据包含唯一交接 ID、实际 prompt、可选 negativePrompt、来源档案 ID 与版本快照。按钮在上游已生成的视觉 Prompt 可用时启用。交接原样传递当前选定或编辑后的 Prompt，不追加系统风格、服装、装备、构图或翻译，不在图片工作台调用内容生成。

旧 NPC 档案若只有叙事字段而没有视觉 Prompt，先在游戏内容工作室提供明确的视觉 Prompt 生成步骤，完成后才能一键交接；不能偷偷用固定模板替代用户内容。世界档案遵循同样规则。上游保留提示词生成和编辑能力。

游戏内容工作室与世界构建中的明确交接都导航至统一图片页；资产库中的历史 Prompt 同样可以原样带入。图片生成保存生成瞬间的请求快照，后续编辑不改变该图片历史。

## 保存与兼容

已带入档案的图片默认保存回该来源，归属在保存区域可见且可改为独立保存或选择其他已有档案；纯手写默认独立保存。归属不影响生成按钮可用性，不自动创建空白内容条目。来源已删除或读取失败时提示改为独立保存，不丢失输入或图片。

内容工作室提供已有档案列表及明确的新建动作，不因切换类别自动制造多个空白草稿。保留旧草稿数据，但未命名空白草稿不占用主要档案选择列表；有内容的旧草稿可在草稿入口继续编辑并命名。保存、重命名保持稳定 ID，历史不可覆盖。

数据库类别校验、类型声明、迁移兼容及列表筛选同步支持服饰。维持现有额度和鉴权；不推送、不部署，不删除用户文件或其他聊天工作树。

## 组件边界

App 负责导航和统一交接。游戏内容工作室承接现有 ContentWorkspace 的设计与档案能力；世界观入口复用 CreationWorkspace。独立图片工作台承接 ContentImageEditor，不能继续由包含设计表单的 ContentWorkspace 的 images 分支渲染。拆分服务与状态接口按既有模块增量调整，避免并行资产库或重复 Prompt 管线。

## 验收与验证

1. 导航只有一个图片工作台，无独立美术生产；游戏内容工作室可访问六类内容。
2. 世界、角色和其他类别在上游产生 Prompt 后，点击交接直接看见原文输入，不出现分类或草稿门槛。
3. 编辑带入文本与纯手写都可生图，API 请求和保存快照与实际文本一致。
4. 旧 NPC、世界、草稿、Prompt 和图片可继续读取；新增服饰可以生成设计并保存、重开、筛选和关联图片。
5. 切换类别不制造空白草稿；新交接不覆盖未保存的用户编辑；生成或保存失败可恢复。
6. 浏览器核对主要布局、交接、生成、保存及刷新；运行完整串行测试、构建与 lint。模拟提供方的验证与真实模型、生产存储验证明确区分。

## 选择依据

采用独立图片页并复用现有图片服务，能移除造成误解的表单，同时保留来源追溯。仅隐藏当前分类区域会继续混用内容与图片状态；重建整套资产服务会增加无关风险，因此不采用。
